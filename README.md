## About Extratastic

Extratastic targets Minecraft Java Edition 1.7.10 and makes the opening stages of the game intentionally demanding. Its progression is built around Tinker's Construct, with revised tool recipes, tougher hunger and regeneration rules, and a setup in which vanilla tools can still be crafted but are not intended for standard use.

The pack combines multiple styles of play in one environment: technology, magic, exploration, farming, and convenience improvements. Applied Energistics 2, Thaumcraft, Thermal Dynamics, Biomes O' Plenty, Waystones, JourneyMap, Treecapitator, and zoom functionality broaden options for storage, travel, discovery, resource gathering, and long-term development. Progress is not directed by a quest book, allowing players to establish their own objectives.
